7STARBOYS — Community Website

This package contains the existing 7STARBOYS HTML pages with a unified responsive visual theme.

Pages: index.html, home.html, login.html, register.html, member.html, members.html, profile.html, admin-panel.html, admin.html.

Styles: theme.css (shared premium dark theme).

Important: Firebase Auth/Firestore and Cloudinary behavior still depends on the existing project configuration, Firestore rules, and live service settings. This package has not been tested against the live Firebase project. Do not treat visual changes as proof that every backend feature works.
